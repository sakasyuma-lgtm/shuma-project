# 図形の証明 学習アプリ

中学2年生向けの図形の証明を練習できる学習アプリです。問題はランダムに生成され、何度でも練習できます。

## 機能

### 問題の種類

1. **三角形の合同証明**
   - SAS（2辺とその間の角）
   - ASA（1辺とその両端の角）
   - SSS（3辺）

2. **二等辺三角形の性質**
   - 底角・頂角の関係
   - 対称性を利用した証明

3. **平行線と角**
   - 錯角・同位角の性質
   - 平行四辺形の証明

4. **対頂角の性質**
   - 対頂角を利用した証明

### 使い方

1. **問題を確認する**
   - 図形が表示されます
   - 条件（仮定）を確認します
   - 証明すべき結論を確認します

2. **証明を作成する**
   - 「理由を選択」ドロップダウンから適切な理由を選びます
   - テキストボックスに証明の内容を入力します（例：AB = CD）
   - 「ステップを追加」ボタンをクリックします
   - 必要なステップを順番に追加していきます

3. **答え合わせ**
   - 「答え合わせ」ボタンで正解かどうか確認できます
   - 「ヒント」ボタンで次のステップのヒントが表示されます
   - 「解答を表示」ボタンで模範解答が表示されます

4. **新しい問題**
   - 「新しい問題を生成」ボタンで別の問題に挑戦できます

## ファイル構成

- `index.html` - メインのHTMLファイル
- `styles.css` - スタイルシート
- `app.js` - アプリケーションのロジック

## 開き方

ブラウザで `index.html` を開くだけで使用できます。インターネット接続は不要です。
