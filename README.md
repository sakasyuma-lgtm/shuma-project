# 図形の証明 学習アプリ

中学2年生向けの図形の証明を練習できる学習アプリです。基礎から丁寧に解説し、問題はランダムに生成されるので何度でも練習できます。

## 機能

### 📖 解説モード

図形の証明について、基礎から丁寧に解説します。

1. **三角形の合同条件**
   - SSS（3組の辺）
   - SAS（2組の辺とその間の角）
   - ASA（1組の辺とその両端の角）
   - 図解付きでわかりやすく説明

2. **よく使う図形の性質**
   - 対頂角は等しい
   - 平行線の錯角・同位角
   - 二等辺三角形の性質
   - 共通な辺の使い方

3. **証明の書き方**
   - 証明の基本的な流れ（4ステップ）
   - 具体的な例題と模範解答
   - 証明のコツ（6つのポイント）

### ✏️ 練習モード

ランダムに生成される問題で、証明の練習ができます。

**問題の種類：**

1. **三角形の合同証明**
   - SAS（2辺とその間の角）
   - ASA（1辺とその両端の角）
   - SSS（3辺）

2. **二等辺三角形の性質**
   - 底角・頂角の関係
   - 対称性を利用した証明

3. **平行線と角**
   - 錯角・同位角の性質
   - 平行四辺形の証明

4. **対頂角の性質**
   - 対頂角を利用した証明

## 使い方

### 解説モードで学ぶ

1. アプリを開くと、最初に**解説モード**が表示されます
2. 三角形の合同条件（SSS、SAS、ASA）について学びます
3. 図形の性質（対頂角、平行線、二等辺三角形など）を確認します
4. 証明の書き方の流れとコツを理解します
5. 例題を見て、証明の組み立て方を学びます

### 練習モードで実践

1. **「練習モード」タブ**をクリックして切り替えます
2. **問題を確認する**
   - 図形が表示されます
   - 条件（仮定）を確認します
   - 証明すべき結論を確認します

3. **証明を作成する**
   - 「理由を選択」ドロップダウンから適切な理由を選びます
   - テキストボックスに証明の内容を入力します（例：AB = CD）
   - 「ステップを追加」ボタンをクリックします
   - 必要なステップを順番に追加していきます

4. **答え合わせ**
   - 「答え合わせ」ボタンで正解かどうか確認できます
   - 「ヒント」ボタンで次のステップのヒントが表示されます
   - 「解答を表示」ボタンで模範解答が表示されます

5. **新しい問題**
   - 「新しい問題を生成」ボタンで別の問題に挑戦できます

## ファイル構成

- `index.html` - メインのHTMLファイル

## 開き方

ブラウザで `index.html` を開くだけで使用できます。インターネット接続は不要です。
